# sortrepo

Sort validation gates for repo inputs before they hit prod.

**Site:** https://theworker02.github.io/sortrepo/

## Install / run

```bash
git clone https://github.com/theworker02/sortrepo.git
cd sortrepo
node src/cli.js
node --test
```
